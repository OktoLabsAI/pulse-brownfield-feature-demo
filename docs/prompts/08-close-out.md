# 8. Close-out (Validator)

Give this to your **Validator** agent once all six tasks are `done`.

---

Confirm every implementation task is approved and every test task's scenario
has genuinely passed, not just executed. If all six clear, submit the sprint
evaluation to close Sprint 1, then mark the spec complete.

If anything hasn't genuinely cleared, don't close the sprint — send the
outstanding task back through [Validation](06-validation.md) instead.

---

That's the full pipeline: Ideation → Refinement → Spec → Sprint → Tasks →
Validation → Close-out, each stage gated on the one before it actually
clearing, not just being claimed.
